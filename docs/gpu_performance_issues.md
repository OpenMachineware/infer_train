## 1. MV模板问题 - 修复后状态

### 根因发现 (2026-09-29)

**Benchmark Bug已修复:**
- 问题: `generate_qXk_blocks(m, 42)` 只生成了 `m` 个blocks
- 正确: 需要 `m * (k / 256)` 个blocks (rows * blocks_per_row)
- 影响: M=16384时只用了1/16的数据，导致GFLOPS计算错误
